# رَصد | RASD

نموذج أولي **تجريبي** لمساعدة الممرضة المدرسية في رصد المؤشرات الصحية باستخدام
التصوير الحراري ومستشعر PPG.

> ⚠️ محاكاة ببيانات اصطناعية فقط. لا يشخّص ولا يطمئن، والقرار النهائي للممرضة.

## التشغيل
```bash
python demo.py                 # PYTHONPATH=src إن لم تثبّت الحزمة
pip install pytest && pytest   # 27 اختبارًا
```

## الهيكل
```
src/rasd/engine.py      التقييم ودمج الإشارات
src/rasd/notifier.py    القنوات + موزّع الإشعارات (تهدئة، تصعيد، فشل قناة)
src/rasd/pipeline.py    قراءة -> تقييم -> إشعار -> سجل تدقيق
tests/                  الحدود والمدخلات الخاطئة والإشعارات
docs/                   المعمارية والتصميم وبنود تحتاج قرار مختص
legacy/prototype_v0.py  النسخة الأولى كما كتبتها للمقارنة
```
